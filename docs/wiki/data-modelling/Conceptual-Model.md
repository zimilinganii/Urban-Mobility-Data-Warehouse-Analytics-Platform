# Conceptual Model

The conceptual model describes the business without committing to SQL tables.

## Main business concepts

- Trip
- Pickup location and dropoff location
- Pickup and dropoff time
- Vendor
- Payment method
- Rate code
- Taxi zone
- Optional weather observation

## First business questions

- How many trips occur by time and location?
- How do distance, duration, fare, and tips vary?
- How do payment types and vendors compare?
- Can weather be related to trip activity if enrichment is added?
