# Power BI

Power BI will consume the curated SQL Server warehouse rather than act as the primary data-cleaning engine.

## Candidate analysis areas

- Executive overview
- Trip analysis by date, hour, day, and month
- Location analysis by borough and pickup/dropoff zone
- Revenue analysis by fare, tips, tolls, totals, and payment type
- Weather analysis if enrichment is implemented
- Historical trends with source-comparability caveats

Candidate measures include total trips, total revenue, average fare, average distance, average duration, average tip, passenger count, trips per day, and trips per hour.
